Context: [context/viewer.md](../context/viewer.md).

The About window: viewer name + version (from the crate version / git
describe at build time), the connected grid and region + its simulator
version (`RegionHandshake` / login response data already held), runtime
system info (OS, GPU/renderer as reported by wgpu, CPU, memory), all
**copyable to the clipboard as one block** — the support workflow the
reference's "Copy to clipboard" exists for — plus credits and the
third-party license texts (generate from `cargo about` or similar at build
time rather than hand-maintaining).

Reference (Firestorm, read-only): `llfloaterabout`, `floater_about.xml`.

Builds on: session/region state and build-time metadata.

**Done (2026-08-13).** New viewer module `about_floater.rs` (Help ▸
About; deferred build-once floater, tabs Info / Credits / Licenses):

- **Simulator version**: the reference takes it from
  `AgentMovementComplete` `SimData.ChannelVersion` (NOT RegionHandshake
  or login response — neither carries it); our client dropped that
  payload, so sl-proto gained `Event::SimulatorVersion(String)`,
  emitted on the root arm and on a confirmed teleport-handover child
  arm (lifecycle tests extended). Sim host rides the existing
  `CircuitEstablished` / `RegionChanged` events.
- **Build metadata**: `build.rs` embeds `git describe --tags --always
  --dirty` (worktree-aware rerun-if hints) + Bevy/wgpu versions parsed
  from `Cargo.lock`; `build_info.rs` exposes them. The login
  channel/version defaults now report the full `0.1.0+<describe>`
  version to the grid (user decision).
- **Support block**: pure unit-tested `support_block()`; English
  labels regardless of locale (user decision — grep-able for support);
  every session field optional ("(not connected)" pre-login). Copy to
  Clipboard copies the displayed block byte-for-byte via the shared
  `clipboard.rs`.
- **Licenses**: generated by `scripts/generate-third-party-licenses.sh`
  (cargo-about; config `about.toml` mirrors the deny.toml allowlist)
  into a committed `assets/licenses/third-party-licenses.txt`,
  embedded via `include_str!` and browsed in a two-pane list (one
  entry per distinct license text, labelled by first using crate).
  Freshness is enforced by the new ggh check
  `rust:::cargo-about-outdated` (git config `repo.cargoaboutoutput` /
  `repo.cargoabouttemplate`, set in this repo).
- **Headless verify affordance**: `SL_VIEWER_OPEN_FLOATER=<ids>` opens
  floaters at startup for screenshot runs.

Live-verified on local OpenSim (screenshot run): full support block
incl. `Simulator version: OpenSim 0.9.2.1 Yeti Dev …`. Interactive
checks (tab switch, copy-paste, license browsing, teleport version
update, menu check mark) still pending a live operator.
